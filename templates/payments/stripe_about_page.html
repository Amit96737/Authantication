Stripe Integration Lifecycle

  • The admin adds items through the Django Admin Panel, where the status is set to is_sold = False by default.
  • The user can view the complete list of all available active items on the dashboard.
  • When the user clicks on checkout, the Stripe API is triggered on the backend and the user securely processes the payment.
  • Upon a successful payment transaction, an asynchronous Stripe Webhook is automatically triggered.
  • Once the webhook executes successfully, the status of the item in the database (DB) mutates to is_sold = True.
  • After the status updates to true, the sold item is completely excluded and hidden from the user dashboard.
Database State Machine Diagram
1. Item Added is_sold = False
2. Checkout Stripe Pay Hit
3. Webhook Success is_sold ➔ True
